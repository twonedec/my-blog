지난 1편에서는 **'월간 검색량 대비 총 문서수(경쟁 포화도)'**를 계산해 초특급 빈집을 찾는 공식을 공개했습니다.  
그런데 1편을 실천해 보신 분들 중에 이런 질문을 주신 분들이 계셨습니다.

> *"알려주신 공식은 너무 좋은데... 처음 검색창에 넣을 **'단어(시드 키워드)' 자체가 잘 안 떠올라요.**  
> 남들이 다 아는 단어 말고, **검색창에 아직 드러나지 않은 숨은 꿀 키워드**는 어떻게 찾나요?"*

상위 1% 마케터들과 시중 15만원짜리 유료 프로그램들이 쓰는 극비 기술이 있습니다.  
바로 **네이버 검색창 뒤에 한글 자음인 `ㄱ`, `ㄴ`, `ㄷ` ... `ㅎ` 14개를 덧붙여 숨겨진 자동완성을 싹 긁어모으는 [자음 롱테일 확장 기술]**입니다.

오늘 이 로직을 100% 구현한 파이썬 스크립트와, 초보자가 속기 쉬운 **'가짜 빈집'을 1초 만에 발라내는 4대 지표 공식**을 공개합니다.

---

## 🔍 1단계: 'ㄱ~ㅎ' 자음 롱테일 자동완성의 원리

예를 들어 네이버에 그냥 `로봇청소기`라고 치면 누구나 다 아는 대형 키워드만 나옵니다.  
하지만 뒤에 자음을 붙여보면 전혀 다른 세상이 펼쳐집니다:

* `로봇청소기 ㄱ` ➔ 로봇청소기 **가성비**, 로봇청소기 **걸레냄새**, 로봇청소기 **고양이**
* `로봇청소기 ㅂ` ➔ 로봇청소기 **문턱**, 로봇청소기 **배터리교체**, 로봇청소기 **비교**
* `로봇청소기 ㅊ` ➔ 로봇청소기 **층간소음**, 로봇청소기 **추천 2026**

실제 소비자들이 불편함을 겪고 해결책을 찾으려고 검색창에 친 **초특급 알짜 롱테일 키워드**들입니다.  
네이버의 비공개 자동완성 엔드포인트(`ac.search.naver.com/nx/ac`)를 호출하면, 14개 자음 뒤에 붙는 롱테일 키워드 수십 개를 1초 만에 긁어올 수 있습니다.

## ⚠️ 2단계: "이 2개 숫자만 보면 속는다!" — 가짜 빈집 판별 4대 지표

검색량 3,000회에 총 문서수가 500개라 "대박 빈집이다!" 하고 글을 썼는데도 조회가 안 나오는 경우가 있습니다.  
이유는 **'가짜 빈집'**이기 때문입니다. 반드시 아래 4대 지표를 교차 검증해야 합니다:

| 분석 지표 | 의미 | 판정 기준 |
|---|---|---|
| **1. 경쟁 포화도** | 총 문서수 ÷ 월간 총검색량 | **0.3 이하 💎S급**, 0.8 이하 ⭐A급 |
| **2. 최신글 경과일** | 1~3위 상위 글이 며칠 전에 올라왔는가? | **30일 이상 전**이면 묵은 글이라 쉽게 탈환 가능 |
| **3. 최근 30일 신규글수** | 최근 한 달간 새로 발행된 글이 몇 개인가? | **5건 이하**면 경쟁이 없는 꿀 빈집! (10건 이상이면 위험) |
| **4. 광고 상업성** | 네이버 검색광고 경쟁 입찰 지수 | '높음'일수록 애드포스트 광고 단가가 비쌈 |

## 💻 3단계: [원클릭 AI 프롬프트] 데스크탑 앱(GPT, Claude, Gemini)에 복붙하세요

터미널이나 파이썬 환경 설정 없이, **ChatGPT 데스크탑, Claude Code, Google Antigravity 등 어떤 AI 데스크탑 앱이든** 아래 프롬프트를 복사해 붙여넣으세요.  
네이버 14개 자음 롱테일을 전수 발굴하고 엑셀까지 자동으로 생성해 주는 **나만의 데스크톱 툴을 10초 만에 제작**해 줍니다.

```text
아래 제공된 [네이버 자음 롱테일 발굴 및 4대 정밀 분석 엔진]을 기반으로, 시드 키워드를 입력하면 엑셀 파일(.xlsx)로 자동 저장해 주는 파이썬 자동화 스크립트를 작성해줘.

[상세 구현 스펙]
1. 동작 프로세스:
   - 시드 키워드(예: "로봇청소기")를 입력받음
   - 네이버 검색창 ㄱ~ㅎ 자음 자동완성(ac.search.naver.com)을 멀티스레드로 동시 호출하여 롱테일 키워드 50~100개 발굴
   - 각 키워드마다 네이버 검색 API(NCP API HUB 우선)를 통해 '총 문서수', '최신글 작성일', '최근 30일 신규글 수'를 수집
   - 네이버 검색광고 API로 월간 총 검색량 조회
2. 엑셀 출력 서식 (openpyxl):
   - 시트명: "🏆 황금키워드 전수분석" (단일 시트)
   - 컬럼 구성: [순번, 키워드명, 황금 등급, 점수, 월간 총검색량, 블로그 총발행량, 포화도, 최신글 경과일, 최근30일 신규글수]
   - '💎 S급 (초특급 빈집)' 행은 연녹색(DCFCE7), '⭐ A급 (우수 빈집)' 행은 연파랑(EFF6FF) 하이라이트 적용
3. 의존성 자동 설치: openpyxl, requests 패키지 안내

[내 네이버 API 키]
- CUSTOMER_ID: "여기에_고객ID_7자리_입력"
- SEARCHAD_API_KEY: "여기에_검색광고_API키_입력"
- SEARCHAD_SECRET_KEY: "여기에_검색광고_SECRET키_입력"
- NAVER_CLIENT_ID: "여기에_NCP_Client_ID_입력"
- NAVER_CLIENT_SECRET: "여기에_NCP_Client_Secret_입력"

[핵심 자음 자동완성 수집 로직]
import requests
from concurrent.futures import ThreadPoolExecutor

def fetch_autocomplete_jamo(seed: str):
    url = "https://ac.search.naver.com/nx/ac"
    headers = {"User-Agent": "Mozilla/5.0"}
    jamos = ["ㄱ", "ㄴ", "ㄷ", "ㄹ", "ㅁ", "ㅂ", "ㅅ", "ㅇ", "ㅈ", "ㅊ", "ㅋ", "ㅌ", "ㅍ", "ㅎ"]
    results = set()

    def get_one(j):
        params = {"q": f"{seed} {j}", "con": 1, "frm": "nv", "ans": 2, "r_format": "json", "r_enc": "UTF-8", "t_koreng": 1}
        try:
            r = requests.get(url, params=params, headers=headers, timeout=3).json()
            items = r.get("items", [[]])[0]
            return [it[0] for it in items if it and len(it[0]) > len(seed)]
        except:
            return []

    with ThreadPoolExecutor(max_workers=7) as executor:
        for kws in executor.map(get_one, jamos):
            for kw in kws: results.add(kw)
    return list(results)
```
