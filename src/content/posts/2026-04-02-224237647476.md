## 결론부터: 당신의 목적이 환경을 결정합니다

Claude Code를 처음 접하면 선택지부터 막힙니다. 웹에서 쓰면 되는 건지, 앱을 깔아야 하는 건지, 터미널이라는 걸 건드려야 하는 건지. 환경마다 할 수 있는 일의 범위가 완전히 다르기 때문에, 잘못된 환경에서 시작하면 "이게 왜 이렇게 불편하지"라는 인상으로 끝납니다.

핵심 선택 기준은 하나입니다. **실제로 무언가를 만들어야 하는가, 아니면 대화로 끝나는 작업인가.**

- 글쓰기·요약·번역 → 웹 또는 데스크톱 앱으로 충분
- 파일 관리·자동화·웹페이지 제작 → 터미널(CLI) 필수
- 기존 코드를 보면서 수정 → VS Code 확장

이 기준 하나만 잡아도 시행착오를 크게 줄일 수 있습니다.

## 웹과 데스크톱 앱 — 언제까지 이걸로 버틸 수 있나

`claude.ai`는 설치 없이 브라우저에서 바로 쓸 수 있습니다. 파일 하나씩 업로드해서 요약을 받거나, 긴 글을 다듬거나, 아이디어를 정리하는 용도라면 충분합니다. ChatGPT나 제미나이 웹 버전과 비슷한 경험이고, Claude는 특히 긴 문서나 글쓰기 품질 면에서 차별점이 있습니다.

데스크톱 앱은 웹보다 UI가 안정적이고, 로컬 파일 접근 범위가 조금 더 넓습니다. 매일 Claude를 대화 도구로 쓴다면 앱을 설치하는 쪽이 편합니다. 단, 터미널처럼 폴더 전체를 제어하거나 명령어를 직접 실행하는 수준은 아닙니다.

두 환경의 공통 한계는 명확합니다. 결과물을 **AI가 대신 만들어 주는 게 아니라, 만드는 법을 알려주는 수준**에 머뭅니다. 그걸 실행하는 건 여전히 사람의 몫입니다.

## 터미널이 달라지는 이유 — "알려주는 AI"에서 "실행하는 AI"로

Claude Code CLI(터미널 버전)를 처음 실행하면 겉보기엔 다른 AI 채팅창과 크게 다르지 않습니다. 그런데 여기서 "이 폴더 정리해줘"라고 입력하면, 실제로 정리됩니다.

웹에서 같은 요청을 하면 명령어를 알려줍니다. 터미널에서는 Claude가 명령어를 직접 작성하고 실행합니다. 오류가 나면 원인을 파악하고 다시 시도합니다. 방향만 제시하면 실행 과정 전체를 Claude가 담당합니다.

코딩 지식이 없어도 됩니다. 터미널 문법도 몰라도 됩니다. 말로 설명할 수 있는 작업이라면, 실행시킬 수 있습니다. 블로그 자동화 시스템, 가족 전용 웹페이지, 아이들용 학습 앱까지, 코드를 배우지 않고도 한 달 안에 만들어낼 수 있다는 게 직접 확인된 사실입니다.

**플랜 모드**를 활용하면 불안감도 줄어듭니다. 실행 전에 "이런 순서로 진행하겠습니다"라는 계획을 먼저 보여주기 때문에, 예상과 다른 방향으로 진행되는 것을 막을 수 있습니다.

## VS Code는 누구에게 필요한가

VS Code 확장은 코드 편집기 안에서 AI 도움을 받는 방식입니다. 코드를 보면서 "이 부분 수정해줘", "여기 버그 찾아줘"라고 바로 요청할 수 있습니다.

이미 코드를 작성하고 있는 분들에게는 터미널보다 더 직관적인 환경입니다. 반면 처음부터 무언가를 만들려는 비개발자라면, VS Code 자체를 배우는 과정이 먼저 필요해서 진입 비용이 높습니다. 이 경우라면 터미널 CLI를 먼저 익히는 쪽이 훨씬 빠릅니다.

## Claude Code vs Cursor vs ChatGPT — 비개발자 관점 비교

Claude Code와 비슷한 포지션의 도구들을 비교해볼 필요가 있습니다.

| 도구 | 파일 직접 제어 | 비개발자 접근성 | 특징 |
|---|---|---|---|
| ChatGPT | 제한적 | 높음 | 대화 특화, 실행 능력 약함 |
| Cursor | 가능 | 보통 | VS Code 기반, 코드 중심 |
| Claude Code CLI | 가능 | 생각보다 높음 | 자연어 지시로 실행까지 |

Cursor는 코드를 이미 다루는 분들에게 강력한 도구지만, 처음부터 비개발자가 쓰기엔 기반 지식이 필요합니다. ChatGPT는 접근성은 높지만 "실행"보다 "안내"에 가깝습니다. Claude Code CLI는 자연어로 명령하고 실행까지 이어지는 흐름이 비개발자에게 오히려 더 맞는 구조입니다.

## 비개발자를 위한 단계별 진입 전략

처음부터 터미널을 열어야 할 필요는 없습니다. 아래 순서로 진입하면 각 단계에서 무엇이 가능한지 체감하면서 다음 단계로 넘어갈 수 있습니다.

1. **웹(claude.ai)** — 먼저 글쓰기·요약·아이디어 정리부터 시작
2. **데스크톱 앱** — 매일 쓰게 되면 앱으로 전환, UI 안정성 확보
3. **터미널 CLI** — 파일 관리나 자동화가 필요한 시점에 설치

3단계로 넘어가는 시점은 간단합니다. "AI가 알려주는 것"만으로 부족하고, "AI가 직접 해줬으면" 싶을 때입니다.

## 주의사항 — 이것만 알고 시작하세요

터미널 환경에서 Claude Code를 쓸 때 한 가지 주의할 점이 있습니다. Claude가 실행하는 명령어는 실제로 파일을 수정하거나 삭제할 수 있습니다. 요청을 명확하게 전달하는 것과, 플랜 모드로 계획을 먼저 확인하는 습관이 중요합니다.

또한 Claude Code는 Pro 플랜($20/월) 기준으로 사용하는 것이 현실적입니다. 무료 플랜은 사용량 제한이 있어 본격적인 작업에는 빠르게 한계에 부딪힙니다. 하루 1-2시간 정도 실제 작업에 활용한다면 월 2만 원대 비용 대비 효율은 충분히 납니다.

방향을 정하는 건 사람의 역할입니다. 그 방향을 실행하는 건 Claude가 합니다. 역할 분담을 명확히 하면, 코딩을 모르는 사람일수록 체감되는 변화가 더 큽니다.
