## 결론부터: "가능하다, 단 이 세 원칙을 알고 시작해야 한다"

바이브 코딩은 실제로 작동한다. AI에게 원하는 것을 설명하면 코드를 만들어주고, 브라우저에서 바로 실행되는 결과물이 나온다. 단, "말만 하면 뚝딱"이라는 기대는 잠시 접어두자. 코딩 지식 없이 시작한다면 반드시 알아야 할 세 가지가 있다.

1. 코드 요청 전 반드시 기획 대화를 먼저 할 것
2. 기능을 한 번에 요구하지 말고 뼈대부터 조각조각 추가할 것
3. 수정 시 "기존 코드는 건드리지 말고 추가만 해달라"고 명시할 것

이 세 원칙을 모르면 20번의 시도가 필요하다. 알고 시작하면 5번 안에 원하는 결과를 얻을 수 있다.

## 바이브 코딩이란, 그리고 무엇을 만들 수 있나

바이브 코딩(Vibe Coding)은 프로그래밍 언어 대신 자연어로 AI에게 지시해서 프로그램을 만드는 방식이다. "타이머 있는 타자연습 만들어줘"라고 말하면 AI가 HTML과 JavaScript 코드를 작성해준다.

상업용 앱이나 복잡한 서비스는 아직 무리지만, 아래와 같은 소형 도구라면 충분히 만들 수 있다.

- 어린이 영단어 암기장
- 자동 계산기 (이자, 용돈 관리 등)
- 타자연습 프로그램
- 교과 내용 퀴즈 페이지

초보자에게는 웹 브라우저에서 바로 열리는 **HTML + JavaScript 조합**이 가장 적합하다. 별도 설치 없이 파일 하나로 실행되기 때문이다.

---

## 실전 3단계: 이 순서대로만 하면 된다

### STEP 1. 만들기 전에 AI에게 "기획 질문"부터 받아라

가장 흔한 실수는 "타자연습 만들어줘"라고 바로 요청하는 것이다. AI는 알아서 판단해서 자신이 생각하는 기본형을 만들어주는데, 내가 원하는 것과 다를 가능성이 높다.

대신 이렇게 접근하자.

> "코딩을 전혀 모르는 초보야. 어린이용 타자연습 웹페이지를 HTML과 JS로 만들고 싶어. 코드는 아직 짜지 말고, 내가 먼저 결정해야 할 기능과 기획 요소들을 리스트로 질문해줘."

AI는 단어장 구성, 타이머 여부, 정답·오답 처리 방식, 종료 조건 같은 항목을 하나씩 물어볼 것이다. 이 대화만 잘 마쳐도 이후 결과물의 완성도가 완전히 달라진다.

![기획 단계 AI 대화 화면](/images/2026-03-16-224218413685/img_02.png)

### STEP 2. 핵심 기능 하나만 먼저 만들어라

기획이 끝났다고 "완성본"을 한 번에 요청하면 안 된다. 가장 기본적인 뼈대부터 시작한다.

> "기획 내용 바탕으로 코딩 시작할게. 타이머나 디자인은 일단 빼고, 단어를 맞히면 다음 단어로 넘어가는 핵심 기능만 먼저 만들어줘."

AI가 준 코드를 메모장에 붙여넣고 `.html`로 저장한 뒤 더블클릭하면 브라우저에서 바로 실행된다. 기능이 제대로 작동하는 것을 확인한 다음에 STEP 3으로 넘어간다.

### STEP 3. 기능 추가 시 "기존 코드 보호" 문구를 반드시 넣어라

새 기능을 추가할 때 가장 자주 발생하는 문제가 기존 기능이 함께 망가지는 것이다. 아래 문구를 요청에 반드시 포함시키면 이 문제를 막을 수 있다.

> "60초 타이머 추가하고 싶어. 기존 단어 넘어가기 기능은 절대 건드리지 마. 전체 코드 다시 짜지 말고, 내 기존 코드의 어느 줄에 추가하면 되는지만 알려줘."

위치를 정확히 물어보면 AI는 "`<body>` 태그 바로 아래에 이 한 줄 추가하세요"처럼 붙여넣기만 하면 되는 수준으로 안내해준다.

## 비전공자가 빠지는 함정 3가지 — 미리 알면 시간이 절반으로 줄어든다

![에러 발생 화면 예시](/images/2026-03-16-224218413685/img_03.png)

**함정 1: "다시 만들어줘"를 반복한다**
전체를 계속 다시 짜달라고 하면 오류가 누적된다. 문제가 생겼을 때는 "이 기능이 왜 안 되는지 원인부터 설명해줘"라고 물어보는 게 훨씬 빠르다.

**함정 2: 에러 메시지를 무시한다**
화면이 깨지거나 기능이 멈추면 브라우저에서 F12를 눌러 콘솔 창을 열어보자. 빨간 에러 메시지가 보이면 그 내용을 그대로 AI에게 붙여넣으면 원인을 바로 찾아준다.

**함정 3: 파일을 `.txt`로 저장한다**
메모장의 기본 저장 형식은 `.txt`다. 반드시 "파일 형식"을 "모든 파일"로 바꾼 뒤 파일명 끝에 `.html`을 붙여 저장해야 브라우저에서 실행된다.

## 부모라면 이런 학습 도구를 만들어볼 수 있다

바이브 코딩은 아이와 함께 쓸 맞춤형 학습 도구를 만들기에 특히 유용하다.

- **교과서 단어 암기장**: 학년별 필수 어휘를 직접 입력한 맞춤형 카드 앱
- **구구단 연습기**: 정답을 맞히면 효과음이나 폭죽 애니메이션 추가 가능
- **독서 퀴즈**: 읽은 책 내용을 확인하는 OX 퀴즈 페이지

시중 학습 앱과 달리 광고가 없고, 내 아이에게 필요한 내용만 담을 수 있다는 것이 가장 큰 장점이다.

## 마치며

바이브 코딩은 "AI가 다 해준다"가 아니라 "AI와 대화를 잘하는 사람이 결과를 얻는다"에 가깝다. 기획 단계 대화, 뼈대부터 조각조각 추가, 기존 코드 보호 — 이 세 원칙만 지키면 코딩 지식이 없어도 자신만의 웹 도구를 완성할 수 있다. 한 번 성공하면 다음 아이디어가 바로 떠오르기 시작하는 것도 이 방법의 묘미다.
