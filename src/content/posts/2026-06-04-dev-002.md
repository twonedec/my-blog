> 시리즈 4편 — 코스피/코스닥 전 종목을 대상으로 기술적 신호를 감지해 상위 25개 후보 종목을 추려내는 1단계 로직의 설계 이유와 구현 방식을 다룬다.

---

## 왜 전 종목을 스캔하나

"오늘 살 주식을 찾는다"는 목표에서 첫 번째 질문은 간단하다: **어디서부터 시작하나.**

관심 종목 리스트를 미리 고정해두면 편하지만, 그 바깥에서 발생하는 신호를 놓친다. 코스피 + 코스닥 전 종목(약 2,700–3,000개)을 매일 전부 스캔하는 이유가 여기 있다. 목표는 **"오늘 뭔가 일어나고 있는 종목"** 을 빠짐없이 후보에 올리는 것.

---

## 어떤 신호를 감지하고, 왜 그 신호인가

5가지 기술적 신호를 사용한다. 신호마다 선택한 이유가 다르다.

### 1. 골든크로스 (단기)

```python
# MA5 > MA20 — 전일에는 아니었다가 오늘 처음 크로스
if (ma5 > ma20) and (ma5_prev <= ma20_prev):
    signals.append("골든크로스")
```

5일선이 20일선을 아래에서 위로 뚫는 시점. 핵심은 **"크로스되는 바로 그 날"만 잡는다**는 것이다. 이미 크로스된 채로 며칠 지난 종목은 신호로 처리하지 않는다. 타이밍이 핵심인 단기 신호에서 늦은 진입은 의미가 없기 때문이다.

### 2. MA장기골든크로스 (중기)

20일선이 60일선을 뚫는 것. 단기 골든크로스보다 발생 빈도가 낮고, 나왔을 때 추세 전환의 강도가 더 크다. 단기/중기 신호를 둘 다 감지하는 이유는 **시간축이 다른 두 모멘텀을 같이 보기 위해서다.**

### 3. 거래량 급증

```python
# 오늘 거래량이 20일 평균의 1.5배 이상
if volume / avg_volume_20d >= 1.5:
    signals.append("거래량급증")
```

거래량을 보는 이유는 거래량 자체가 목적이 아니라 **관심도의 변화를 감지하기 위해서다.** 갑자기 거래량이 튀면 호재든 악재든 이유가 있다는 뜻이다. 뭔지는 다음 단계(뉴스 필터)에서 확인한다.

### 4. 신고가

52주 고점의 98% 이상에 도달한 종목. 많은 퀀트 전략에서 모멘텀 팩터로 활용하는 신호다. 신고가 근처는 **저항이 아닌 추진력**으로 해석하는 게 모멘텀 전략의 관점이다.

### 5. 볼린저밴드 하단 + RSI 과매도 (반등 신호)

```python
if price <= bb_lower * 1.02 and rsi <= 35:
    signals.append("볼린저밴드")
```

앞의 네 가지가 추세 추종 성격이라면, 이건 역추세 신호다. 과매도 구간에서 밴드 하단에 걸린 종목은 기술적 반등을 기대할 수 있다. **추세 추종과 역추세를 함께 감지하는 이유**는 시장 국면마다 유효한 전략이 다르기 때문이다.

## 신호가 나왔다고 다 같은 신호가 아니다

신호 유무가 아니라 **강도**가 중요하다. 그래서 신호에 점수를 매긴다.

```python
def compute_signal_score(t: dict, signals, cap: float = 6.0) -> float:
    score = 0.0

    if "골든크로스" in signals:
        vol_ratio = t.get("volume_ratio", 1.0)
        score += 1.5 + (0.5 if vol_ratio > 1.5 else 0)  # 거래량 동반 시 보너스

    if "MA장기골든크로스" in signals:
        score += 1.2

    if "거래량급증" in signals:
        score += 1.0

    if "신고가" in signals:
        score += 1.3

    if "볼린저밴드" in signals:
        score += 1.0

    # 복합 신호 시너지
    if "골든크로스" in signals and "거래량급증" in signals:
        score += 1.0  # 두 신호가 동시에 나오면 더 강함

    return min(score, cap)  # 최대 6.0점
```

점수 설계에서 중요한 결정 두 가지:

1. **골든크로스 + 거래량 급증 조합에 보너스를 준다.** 단독 신호보다 복합 신호가 유의미하다는 경험칙이다.
2. **최대 6.0점으로 상한선을 둔다.** 신호가 많이 겹쳐도 무제한 점수를 주지 않는 것은 과적합을 막기 위해서다.

## 기술적 지표만으로는 부족하다 — 수급 데이터 반영

차트 신호가 강해도 외국인·기관이 파는 종목이라면 신뢰도가 떨어진다. 반대로 차트 신호와 수급이 동시에 들어오면 더 강한 근거가 된다.

```python
# 외인+기관 동시 순매수: +0.7점
if t.get("foreign_net_buy_3d", 0) > 0 and t.get("inst_net_buy_3d", 0) > 0:
    score += 0.7

# 외인만 순매수: +0.5점
elif t.get("foreign_net_buy_3d", 0) > 0:
    score += 0.5

# 당일 순매수 TOP30 포함: +0.5점 (KIS API)
if t.get("in_top30", False):
    score += 0.5
```

매일 장 시작 전에 전일 외인/기관 순매수 TOP30을 조회해서 해당 종목이 포함되면 추가 점수를 준다.

## 잘못된 신호를 억제하는 설계

점수를 올리는 것만큼 **거짓 신호를 제거하는 것**도 중요하다.

**공매도 급증 / 신용잔고 과다 → 감점**

아무리 기술적 신호가 좋아도 공매도가 급증하거나 신용잔고가 과도하면 리스크 신호다. 점수를 깎는다.

**볼린저밴드 + 데드크로스 동시 발생 → 신호 제거**

```python
# MA5 < MA20 < MA60 완전한 데드크로스 구조에서의 볼린저밴드 신호는 제거
if "볼린저밴드" in signals:
    if ma5 < ma20 and ma20 < ma60:
        signals.remove("볼린저밴드")
```

하락 추세 한가운데에서 볼린저밴드 하단에 걸리는 건 반등이 아니라 추락이 계속되는 과정일 수 있다. 이 경우 신호를 아예 제거한다.

## 시장 국면에 따라 기준선을 동적으로 조정한다

매일 약 2,700–3,000개 종목을 스캔하면 신호 종목은 보통 50–150개 정도 나온다. 그런데 시장 국면에 따라 크게 달라진다.

| 시장 상황 | 신호 종목 수 | 이유 |
|---|---|---|
| 상승장 | 200개 이상 | 신고가·골든크로스 대량 발생 |
| 하락장 | 20개 이하 | 신호 자체가 줄어듦 |

이 때문에 threshold를 고정하지 않고 시장 상황에 따라 수동으로 조정할 수 있게 설계했다. 최종적으로 **상위 25개**를 1.5단계(뉴스 필터)로 넘긴다.

## 3,000개를 3–4분 안에 처리하는 방법

전 종목 스캔을 직렬로 처리하면 시간이 너무 걸린다.

```python
with ThreadPoolExecutor(max_workers=5) as pool:
    futures = {
        pool.submit(_scan_one, sym, name, sig_cap, top30): (sym, name)
        for sym, name in universe
    }
```

worker 5개로 병렬 처리. 3,000개 종목 기준 약 **3–4분**에 완료된다. 장 시작 전에 결과가 나와야 하기 때문에 처리 속도는 설계의 실질적인 제약 조건이다.

## 이 방법의 한계

기술적 신호는 과거 데이터 기반이다. 신호가 나왔다고 앞으로 오른다는 보장이 없다. 특히 세 가지 경우가 문제다.

- **갭업 오픈**: 전날 밤 뉴스로 이미 오른 종목이 골든크로스처럼 보이는 경우
- **저유동성 종목**: 거래량이 원래 적어서 조금만 거래해도 거래량 급증 신호가 뜨는 종목
- **테마 과열**: 테마가 달아오른 구간의 신고가는 고점 매수가 될 수 있음

이 한계를 보완하기 위해 1단계 신호 종목 25개를 뉴스 필터(1.5단계)와 AI 판단(2–3단계)으로 추가 걸러낸다. 다음 편에서 계속.
